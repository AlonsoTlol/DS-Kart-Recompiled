DS Kart Recompiled
==================
(Español más abajo)

Mario Kart DS for PC, no emulator. Made by alontube together with Claude.
Fan project not affiliated with Nintendo. The game is NOT included.

How to play
1. Extract this folder anywhere (don't open it from inside the zip).
2. Open Launcher.exe.
3. Pick your language and, in Settings, your EUROPEAN Mario Kart DS ROM
   (.nds, game code AMCP), dumped from your own cartridge.
4. Enter your name and press PLAY.

The first time, the launcher prepares the game: it downloads Python and the
compiler (about 200 MB, from their official sites), translates the code of your
ROM and compiles it for your PC. It takes a few minutes. After that it starts
instantly.

Updates: the launcher tells you when there is a new version; press "Update".
Your ROM, settings and save are kept.

If Windows says "Windows protected your PC": "More info" > "Run anyway"
(it shows up because the program isn't signed).

Local multiplayer: over Radmin VPN or the same network. One player presses
"Create a group", the other picks it from the list and the first one presses
READY. If Windows asks about the firewall, press Allow.
Online: not available yet; coming soon.

WARNING: these are the first versions and they have plenty of bugs. If you find
one, please report it in Issues: https://github.com/AlonsoTlol/DS-Kart-Recompiled/issues

4. Pon tu nombre y dale a JUGAR.

(unos 200 MB, de sus páginas oficiales), traduce el código de tu ROM y lo
compila para tu PC. Tarda unos minutos. Las siguientes veces arranca al momento.

Tu ROM, tus ajustes y tu partida no se tocan.

Si Windows avisa con "Windows protegió su PC": "Más información" > "Ejecutar de
todas formas" (sale porque el programa no está firmado).
