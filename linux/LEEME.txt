DS Kart Recompiled for Linux (beta)
===================================
(Español más abajo)

Mario Kart DS for PC, no emulator. Made by alontube together with Claude.
The game is NOT included: you need a dump of your own cartridge.

1. Install what's needed (once):
     Ubuntu / Debian / Mint:   sudo apt install python3 clang libsdl2-dev
     Arch / Manjaro:           sudo pacman -S python clang sdl2
     Fedora:                   sudo dnf install python3 clang SDL2-devel
     Steam Deck (SteamOS): the system is read-only, so use a container. In Desktop
     Mode, open Konsole in this folder and run (distrobox comes with SteamOS 3.5+):
       distrobox create -i ubuntu:24.04 -n mkds
       distrobox enter mkds
       sudo apt install python3 clang libsdl2-dev
     then do steps 2 and 3 inside that same terminal ("distrobox enter mkds" the
     next times). Not tested on a Steam Deck yet: tell us how it goes!

2. Open a terminal in this folder and run:
     sh linux/jugar.sh
   A launcher window opens. In Settings, choose your EUROPEAN Mario Kart DS ROM
   (game code AMCP) and enter your name, then press PLAY. It also tells you when
   there is a new version. To choose the file it uses zenity or kdialog; without
   them, drag the .nds file onto the window.
   Without a window (Steam Deck in Game Mode, SSH...) copy the ROM to rom/mkds.nds
   and run: sh linux/jugar.sh --terminal

   The first time it translates your ROM's code and compiles it for your PC:
   it takes a while (5 to 30 minutes depending on the CPU). After that it
   starts instantly.

Settings: in ajustes.ini (created the first time): NOMBRE (your name), ESCALA
(1-4, 3D resolution), FPS (60/120/180/240), PANTALLA_COMPLETA (fullscreen 0/1),
IDIOMA (1 English, 2 French, 3 German, 4 Italian, 5 Spanish), MICRO (0/1),
GPU (0/1, 3D on the graphics card), DISPOSICION (0 both screens the same size, 1 big top screen with the small touch
screen beside it, 16:9, 2 big top screen with the small touch screen on top of it).

Controls: arrows = D-pad, X = A, Z = B, S = X, A = Y, Q = L, W = R,
Enter = Start, Backspace = Select, mouse = stylus on the bottom screen,
F1 = settings menu, F11 (or Alt + Enter) = fullscreen, F10 = save replay (needs ffmpeg).
Controllers (Xbox, PlayStation, Switch Pro and others SDL knows): D-pad or left stick; you can change what each
button does in the settings menu > Controllers (there's a Nintendo-style button).

If something fails, open an issue on GitHub with what the terminal says:
https://github.com/AlonsoTlol/DS-Kart-Recompiled/issues


DS Kart Recompiled para Linux (beta)
===================================

Mario Kart DS para PC, sin emulador. Hecho por alontube junto con Claude.
El juego NO viene incluido: necesitas una copia de tu propio cartucho.

1. Instala lo necesario (una sola vez):
     Ubuntu / Debian / Mint:  sudo apt install python3 clang libsdl2-dev
     Arch / Manjaro:           sudo pacman -S python clang sdl2
     Fedora:                  sudo dnf install python3 clang SDL2-devel
     Steam Deck (SteamOS): el sistema es de solo lectura, así que se usa un
     contenedor. En el modo Escritorio, abre Konsole en esta carpeta y escribe
     (distrobox viene con SteamOS 3.5 o superior):
       distrobox create -i ubuntu:24.04 -n mkds
       distrobox enter mkds
       sudo apt install python3 clang libsdl2-dev
     y haz los pasos 2 y 3 en esa misma terminal (las siguientes veces, primero
     "distrobox enter mkds"). Aún no probado en una Steam Deck: ¡cuéntanos!

2. Abre una terminal en esta carpeta y escribe:
     sh linux/jugar.sh
   Se abre el launcher. En Ajustes, elige tu ROM de Mario Kart DS EUROPEO
   (código AMCP) y pon tu nombre, y dale a JUGAR. También avisa cuando hay una
   versión nueva. Para elegir el archivo usa zenity o kdialog; sin ellos, arrastra
   el .nds a la ventana.
   Sin ventana (Steam Deck en modo juego, SSH...) copia la ROM a rom/mkds.nds y
   usa: sh linux/jugar.sh --terminal

   La primera vez traduce el código de tu ROM y lo compila para tu PC:
   tarda bastante (de 5 a 30 minutos según el procesador). Las siguientes
   veces arranca al momento.

Ajustes: en ajustes.ini (se crea la primera vez): NOMBRE, ESCALA (1-4, resolución
del 3D), FPS (60/120/180/240), PANTALLA_COMPLETA (0/1), IDIOMA (1 inglés,
2 francés, 3 alemán, 4 italiano, 5 español), MICRO (0/1), DISPOSICION (0 las
dos iguales, 1 la de arriba grande y la táctil pequeña al lado, 16:9, 2 la de
arriba grande y la táctil pequeña superpuesta).

Controles: flechas = cruceta, X = A, Z = B, S = X, A = Y, Q = L, W = R,
Enter = Start, Retroceso = Select, ratón = lápiz en la pantalla de abajo,
F1 = menú de ajustes, F11 (o Alt + Enter) = pantalla completa, F10 = guardar
repetición (necesita ffmpeg).
Mandos (Xbox, PlayStation, Switch Pro y los que conozca SDL): cruceta o stick
izquierdo; lo que hace cada botón se cambia en el menú de ajustes > Mandos (hay
un botón para ponerlos como en Nintendo). Si el tuyo no va, dínoslo.

Si algo falla, abre un issue en GitHub con lo que salga en la terminal:
https://github.com/AlonsoTlol/DS-Kart-Recompiled/issues
